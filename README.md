The funniest one line a talking elevator could say, in the elevator's own voice — one line, 91 characters.

> You've been rehearsing your breakup speech in my mirror for six months. Floor 9. Good luck.

## How it works

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set), after checking it is a single line of 1–120 characters — the same gate the scorer applies.

```sh
node main.ts
```
